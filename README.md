# BillDesk phone app (built files)

This repository holds only the **built, ready-to-host files** of the BillDesk phone app for Nidha Couture, published with GitHub Pages.
It contains no shop data, no passwords and no secret keys. Nothing from the shop is stored here: bills, customers and stock live in the
shop's private cloud database, and the app reads and writes them only after the owner signs in.

The program source is kept in the shop's private repository.
